# Code Of Conduct

Scalpel contributors are expected to keep technical discussion direct,
evidence-based, and respectful.

## Expected Behavior

- Focus criticism on code, tests, docs, and claims.
- Prefer reproducible examples over broad assertions.
- Respect private project data and never request unnecessary file content.
- Keep security reports private until coordinated disclosure is complete.
- Assume safety claims require proof.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing private file content, secrets, or vulnerability details without
  permission.
- Misrepresenting unproven behavior as a current guarantee.
- Repeatedly ignoring maintainer direction on safety boundaries.

## Enforcement

Maintainers may edit, hide, or remove comments and may restrict participation
when behavior harms project work or user safety.
